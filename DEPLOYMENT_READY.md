## Support & Troubleshooting

### Common Issues & Fixes

**Build fails after deployment?**
- Check Vercel logs
- Verify environment variables
- Run `npm run build` locally

**Analytics not showing?**
- Clear browser cache
- Check Vercel Analytics dashboard
- Wait 5-10 minutes for data

**Images not loading?**
- Verify image URLs are correct
- Check file paths in project
- Ensure alt text is present

**Performance issues?**
- Check Vercel Analytics for slow pages
- Review Core Web Vitals
- Look for third-party scripts
